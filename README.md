# Game Hub

友だちとオンラインで遊べるミニゲーム集です。ホーム画面でゲームを選んでルームを作り、4文字のコード（または招待リンク）を送れば、相手はブラウザだけで参加できます。

- 収録ゲーム：きゅうり（トランプ）、ババ抜き（トランプ）、三目並べ（ボード）
- 見た目：卓上カフェ風（木のテーブル＋フェルトの卓＋紙のカード）
- 技術：Node.js / Express / Socket.IO（素のHTML+JS、ビルド不要）

## 収録ゲーム

| ゲーム | 人数 | ひとこと |
|---|---|---|
| きゅうり | 2〜7人 | デンマークの Agurk。最後のトリックを取ると失点、21点で「きゅうり」1本、2本で脱落 |
| ババ抜き | 2〜6人 | 定番。手札は本人にしか送られない |
| 三目並べ | 2人 | 縦・横・斜めに3つ並べたら勝ち |

きゅうりのルールは [Pagat の Agurk](https://www.pagat.com/last/agurk.html) の基本ルールに沿っています（同じ数字を出した人の減点、21点で1本目→他の人の最高点に戻る、2本目で脱落）。ゲーム画面の「ルール」を開くと遊び方が読めます。

## 手元で動かす

```bash
npm install
npm start
# → http://localhost:3000
```

同じPCで動作を確認するときは、ブラウザのシークレットウィンドウなどで2つ目の画面を開いてください（名前と接続情報は localStorage に保存されるため、通常のタブを並べると同じプレイヤーとして扱われます）。

## 公開する（Render 無料プラン）

1. このフォルダを GitHub にリポジトリとして push する（`node_modules` は不要）
2. https://render.com でログイン → **New → Web Service** → リポジトリを選ぶ
3. 設定
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
4. 発行された `https://xxxx.onrender.com` を友だちに送る

> 無料プランは15分アクセスがないとスリープし、次に開いたときに起動まで1分ほどかかります。遊ぶ前に一度開いておきましょう。
> また、サーバーが再起動するとルームは消えます（ゲームの途中経過は保存していません）。

## しくみ

```
server.js            共通部分：ルーム作成・参加・ロビー・再接続・ゲームの自動読み込み
public/              共通の画面：ホーム → ロビー → ゲーム
  style.css          テーマと、ゲームで使える共通部品（.felt 卓 / .note メモ / .seat 席 / .pcard トランプ / .hand 手札 / .log 記録）
  lib/cards.js       トランプを描く関数 cardHTML()・backHTML()
games/<id>/
  server.js          ルール（状態の作成・操作の判定・各人に見せる情報）
  client.js          そのゲームの画面
  client.css         そのゲームの見た目（任意）
```

- **ルールの判定はすべてサーバー側**で行います。ブラウザ側は「状態を描く」「操作を送る」だけなので、ずるができません。
- サーバーは `view(state, playerId)` で**プレイヤーごとに別の情報**を送ります。ババ抜きでは自分の手札だけ中身を送り、他人の手札は枚数しか送りません。開発者ツールで覗いても他人の手札は見えません。
- このため、全員に同じ盤面が見えるボードゲームと、手札を隠すトランプゲームが同じ仕組みに収まります。

## ゲームを追加する

1. `templates/new-game` を `games/` にコピーし、フォルダ名をゲームID（英小文字）にする
2. `server.js` の `id` をフォルダ名と同じにする
3. `setup` / `action` / `view` / `isOver` を書く
4. `client.js` の `render` で画面を作る
5. サーバーを再起動 → ホーム画面に自動で並ぶ

`server.js` に書くもの：

| 項目 | 役割 |
|---|---|
| `id, name, description, category` | ホーム画面の表示 |
| `cover: { color, mark, markColor }` | ホーム画面の箱の色と、カードに描く1文字 |
| `minPlayers, maxPlayers` | 人数制限（ロビーで自動チェック） |
| `setup(players)` | 開始時の状態を返す |
| `action(state, playerId, action)` | 操作を処理して state を書き換える。違反は `{ error }` を返す |
| `view(state, playerId)` | その人に見せる情報を返す（隠し情報はここで外す） |
| `isOver(state)` | 終了したら true |
| `onLeave(state, playerId)`（任意） | 途中で抜けた人の扱い。書かなければロビーに戻る |

画面側（`client.js`）は、卓を `<div class="felt">…</div>` で囲み、手札はその下に `<div class="hand">` で置くと他のゲームと見た目がそろいます。トランプは `import { cardHTML } from '/lib/cards.js'` で描けます。

### 向いているゲーム・注意が要るゲーム

- そのまま作れる：ターン制のボードゲーム・トランプ・カードゲーム、クイズ、お絵かき伝言、人狼など
- 一工夫が要る：
  - 制限時間付きのゲームは、サーバー側でタイマーを持つ仕組みを足す
  - リアルタイムアクションは、毎秒何十回も送る設計が別途必要
