# 仕様 02：インディアンポーカー（チップなし・パーティー版）

ブランチ：`feature/indian-poker`
前提：CLAUDE.md と 仕様01で入った基盤（`turnOf` / `room` 引数 / `onConnectionChange` / `ctx.prev` / `ctx.sound` / `.g-layout` / `export const rules`）を使う。

## 1. ルール

- 人数：2〜6人。ライフは各自 **3**
- カード：52枚（ジョーカーなし）。強さは数字だけで決まり、**A(14) > K(13) > Q(12) > J(11) > 10 … > 2**。マークは関係なし
- 毎ラウンド、新しくシャッフルした山から、生きている全員に1枚ずつ配る
- 自分のカードは**自分だけ見えない**（おでこに貼るイメージ）。他の人のカードはすべて見える
- 宣言の順番：ラウンドの「最初の人」から時計回りに1人ずつ、**勝負** か **降りる** を宣言する。前の人の宣言は全員に見える。最初の人はラウンドごとに1つずつ時計回りにずらす（脱落者は飛ばす）
- 全員が宣言したら全員のカードを公開し、次の条件に当てはまる人がライフを **−1** する

  | 宣言 | ライフが減る条件 |
  |---|---|
  | 勝負 | 勝負した人の中で、自分の数字が最大でない（最大と同じ数字ならセーフ） |
  | 降りる | 自分の数字が**全員の中で最大**だった（最大と同じ数字も含む）。「もったいない降り」 |

  - 例：全員が降りた場合 → 全員の中で最大の数字の人（同じ数字なら全員）が −1
  - 例：勝負が1人だけで、その人が最大でない場合 → 勝負した人はセーフ（勝負した人の中では最大）。全体で最大なのに降りた人が −1
- ライフが 0 になったら脱落。最後の1人が勝ち
- **全員が同時に脱落する場合**は、そのラウンドのライフ減少をすべて取り消し、同じメンバーで次のラウンドへ進む（ログに「全員アウトなのでノーカウント」と出す）

## 2. サーバー（games/indian/server.js）

### メタ情報
```js
id: 'indian', name: 'インディアンポーカー',
description: '自分のカードだけ見えない！ みんなの反応を読んで、勝負か降りるかを決めよう',
category: 'トランプ', cover: { color: '#7a3b5c', mark: '?', markColor: '#2a1a10' },
minPlayers: 2, maxPlayers: 6
```

### state
```
players, lives: number[], out: boolean[], left: boolean[],
starter: 席番号（このラウンドの最初の人）, round: number,
cards: (card|null)[],          // 席ごとのカード（脱落者は null）
decl: ('fight'|'fold'|null)[], // 宣言
turn: 席番号,
phase: 'declare' | 'reveal' | 'over',
result: { losers: 席番号[], reasons: { [席]: 'lost-fight'|'wasted-fold' }, eliminated: 席番号[], voided: boolean } | null,
ready: 席番号[], winner: 席番号|null, log: string[]
```

### action（第4引数 room = { hostId, connectedIds }）
| type | 条件 | 処理 |
|---|---|---|
| `declare` `{ choice: 'fight'|'fold' }` | phase=declare かつ自分の番 | 宣言を記録して次の人へ。全員宣言したら判定して phase=reveal（勝者が決まれば over） |
| `ready` `{ on: boolean }` | phase=reveal | きゅうりと同じ。needIds（生存かつ接続中）が全員そろったら次のラウンドへ |
| `forceNext` | phase=reveal かつホスト | 待たずに次のラウンドへ |
| `forceFold` | phase=declare かつホスト かつ 手番の人が切断中 | 手番の人を「降りる」扱いにして進める |

- 判定ロジックは純粋関数 `judge(cards, decl, aliveSeats)` → `{ losers, reasons }` として切り出し、テストしやすくする
- `turnOf`：declare のときは手番の人、それ以外は `[]`
- `onConnectionChange`：reveal 中は準備OKの判定をやり直す（きゅうりと同じ）
- `onLeave`：その席を脱落扱い（left=true）。declare 中ならそのラウンドを配り直す。残りが1人以下なら over

### 準備OKの共通化
きゅうりと同じ仕組みなので、`lib/readyCheck.js`（プロジェクト直下。`games/` の外）に切り出す。
```js
needIds(state 用の関数を受け取る) / toggle / isAllReady / reset
```
インディアンポーカーはこれを使う。**きゅうりの置き換えは最後の任意ステップ**（テストが通ることを確認したうえで行う）。

### view（★最重要：自分のカードを漏らさない）
```
players: [{ id, name, lives, out, left, decl, isStarter,
            card: <下記> }]
myId, phase, round, currentId, readyIds, needIds, result, winnerId, log
```
- `card`：
  - phase=declare：**自分の席は必ず `null`**。他人の席はカードを送る
  - phase=reveal / over：全員分を送る
- 宣言（decl）は declare 中も全員に送ってよい（順番に宣言する前提のルールのため）

## 3. 画面（games/indian/client.js / client.css）

### 卓（.g-main 内の .felt）
- 生きている全員を「席」として並べる。各席の内容は次のとおり
  - **おでこのカード**：他人のカードは表向きの大きめのカード（`cardHTML`）。自分の席は裏向き（`backHTML`）の上に大きく「？」を重ね、下に「あなた」と出す
  - 名前チップ。手番は金色（既存の `.seat.turn`）、最初の人には小さく「先」
  - ライフ：小さな丸3つ（残りは赤、失ったものは枠だけ）
  - 宣言バッジ：「勝負」（赤地に白文字）／「降り」（灰色）／「考え中…」（手番の人）／空欄（まだの人）
- 並び順は宣言の順番（最初の人から）にする。左から右へ読めば順番が分かる
- 2〜3人は1列、4〜6人は2段で折り返す（カードの幅は 64px 前後。390px幅で横スクロールさせない）
- メモ（.note）の文言
  - 自分の番：「あなたの番｜勝負する？ 降りる？」。下に大きな2ボタン（**勝負**＝primary、**降りる**＝通常ボタン）。押したら、結果が来るまで両方を無効にする
  - 他人の番：「○○さんが考え中…（あと2人）」
  - 公開後：「結果発表」

### 公開（reveal）
- 自分のカードが裏から表になる演出：CSSの3D回転（rotateY 180deg、0.5秒）。`prefers-reduced-motion` のときは単純に切り替える
- 結果パネル（紙のパネル）で、全員を1行ずつ並べる：カード（sm）、名前、宣言、判定
  - 判定の文言：「セーフ」／「勝負で負け −1」／「降りたけど一番強かった −1」／「脱落」
  - ライフが減った人の行は赤い左線ではなく、**行の背景を薄い赤**にする
  - voided のときは「全員アウトなのでノーカウント」と大きく出す
- 準備OKの一覧とボタンは、きゅうりと同じ見た目・挙動にする
- 決着時は勝者を大きく表示する

### .g-side
- ライフ表：名前、ライフの丸、脱落表示。生存者が上
- 記録（.log）：直近10件。例：「べん：勝負」「しー：降り」「第3ラウンド：あき −1（勝負で負け）」

### ルール（export const rules）
1章の内容を5〜7行の箇条書きにする。−1になる2つの条件は必ず太字にする。

### 効果音（ctx.prev との差分。1回の更新で鳴らすのは最大1つ）
| 優先 | 条件 | 音 |
|---|---|---|
| 1 | over になった | `win` |
| 2 | reveal になり、自分が losers に含まれる | `penalty`（脱落なら `cucumber`） |
| 3 | reveal になった | `flip`（新規） |
| 4 | 誰かの宣言が増えた（勝負） | `card` |
| 5 | 誰かの宣言が増えた（降り） | `ready` |
| 6 | 新しいラウンドになった | `card` |

`sound.js` に `flip` を追加する：ホワイトノイズ 40ms（highpass 2500Hz）＋ sine 880Hz 50ms を重ねた「シュッ・ピン」。

## 4. テスト（test/indian.random.js を追加し、npm test に含める）
- 2〜6人 × 各2000ゲームを、宣言・ready・forceNext・forceFold・切断・再接続・退席の乱択で最後まで回す
- 各ステップで次を検証する
  - **declare 中、全員の view で自分の `card` が null であること**（★漏洩チェック）
  - 他人のカードは declare 中も見えていること
  - ライフが 0〜3 の範囲にあること。脱落者に手番が回らないこと
  - 判定が1章の表どおりであること（`judge` を、表を素直に書いた別実装と突き合わせる）
  - voided のとき、ライフが1つも減っていないこと
  - 終了時に生存者が1人で、その人が winner であること
- `judge` の手書きケース（最低8つ）：全員勝負／全員降り／勝負1人で最大／勝負1人で最大でない／最大が同点で両者勝負／最大が同点で片方降り／2人戦の各パターン／全員アウト（voided）
