# 仕様 06：ダイス領土戦

ブランチ：`feature/dice-war`
前提：CLAUDE.md、仕様01〜05（turnOf / room 引数 / ctx.prev / ctx.sound / .g-layout / rules / 観戦 isOut・spectatorView / チャット / ゲーム設定 options / タイマー deadline・onTimeout / { silent: true }）。
**最初に現状のコードを読み、名前が違う箇所は実際のコードに合わせること。読み替えた箇所は報告に書く。**

## 1. ルール
- 人数：**2〜6人**。手番の順番はゲーム開始時にランダム
- 地図：六角形のマスを集めた **領土**（ゲーム設定で 約20 / 約30 / 約40）。毎ゲーム、ランダムに生成する
- 各領土には持ち主とダイス（**1〜8個**）がある
- **自分の番**：次の「攻撃」を何回でも行い、最後に「ターン終了」
  - 攻撃元：自分の領土で、ダイスが **2個以上**
  - 攻撃先：攻撃元に **隣接する** 他人の領土（中立の領土も含む）
  - 判定：攻撃元と攻撃先の **ダイスを全部振り**、合計を比べる
    - 攻撃側の合計 **＞** 防御側の合計 → 占領。攻撃先の持ち主が自分になり、攻撃元のダイスを **1個残して残り全部** 攻撃先へ移す
    - それ以外（**同点を含む**）→ 失敗。攻撃元のダイスが **1個** になる。攻撃先は変化なし
- **ターン終了時の補充**
  - 獲得数 = 自分の領土のうち、**隣接でつながった最大のかたまりの領土数**
  - 獲得数＋前のターンからの持ち越し分を、ダイスが8個未満の自分の領土に **1個ずつランダムに** 足していく
  - 置ききれなかった分は **持ち越し**（上限 **64個**。超えた分は捨てる）
- 領土が0になったら **脱落**。最後の1人の勝ち
- 念のための打ち切り：全員が**100周**しても決着しなければ、領土数が最も多い人の勝ち（同数なら総ダイス数、それも同じなら引き分け）

## 2. ゲーム設定（options）
| key | 表示 | 選択肢 | 初期値 |
|---|---|---|---|
| `mapSize` | 地図の広さ | 小（約20）/ 中（約30）/ 大（約40） | **中** |
| `turnTime` | 1ターンの制限時間 | 30秒 / 60秒 / 90秒 / なし | **60秒** |

- 時間切れになったら、自動でターン終了（補充あり）にする

## 3. 地図の生成（games/dicewar/map.js として切り出す）
純粋関数 `generateMap({ regions, players, rng })` → `{ width, height, grid, regions }`。

### 盤
- 六角形のマス（**pointy-top、奇数行を右にずらす配置**）
- マスの数は、領土数に合わせて決める（目安：小 18×14、中 22×17、大 26×20）
- `grid`：長さ `width*height` の配列。値は領土番号、海は `-1`

### 作り方
1. 盤の中からランダムに、領土の数だけ「種」になるマスを選ぶ（種同士は3マス以上離す）
2. 各領土を、隣接する空きマスへ1マスずつ順番に広げていく。各領土の目標サイズ（10〜16マスでランダム）に達したら止める
3. 広がらなかった残りのマスは海にする
4. 隣接関係を計算する（マスが辺で接していれば隣接）
5. **検証**して、だめなら最初から作り直す（最大200回。それでもだめなら検証条件を少しゆるめる）
   - すべての領土が1つにつながっている（海を挟んだ孤島を作らない）
   - 各領土のマスが5マス以上で、マス同士がつながっている
   - 各領土の隣接数が1以上
   - 隣接数の平均が2.5以上（一本道のような地図を避ける）

### 初期配置
- 使う領土数を `プレイヤー数 × floor(領土数 / プレイヤー数)` に切り下げ、余った領土は **中立**（持ち主なし。ダイス1〜3個）にする
- 領土をランダムに均等に配る（同じ持ち主の領土が固まりすぎないよう、完全ランダムでよい）
- ダイス：全領土をまず1個にし、各プレイヤーに「持っている領土数 × 2」個の追加ダイスを、自分の領土へランダムに配る（1領土8個まで）
- 中立の領土は、攻撃もされるが自分からは攻撃しない。補充もない

### 領土の情報（地図生成時に計算して持っておく）
```
region = { id, cells: number[], neighbors: number[], center: number /* ラベルを置くマス */ }
```
`center` は、領土の重心にいちばん近い、その領土のマス。

## 4. サーバー（games/dicewar/server.js）

### メタ情報
```js
id: 'dicewar', name: 'ダイス領土戦',
description: 'となりの領土にダイスで攻め込め！ つながった領土が多いほど援軍が増える陣取り合戦',
category: 'ボード', cover: { color: '#9a6a2f', mark: '⚀', markColor: '#2a1a10' },
minPlayers: 2, maxPlayers: 6
```
（cover.mark は、カードに描く1文字。ダイスの目の文字が環境で崩れるようなら「陣」にする）

### 乱数
- `state` を作るときに乱数の関数を注入できるようにする（`setup(players, options, { rng })`。省略時は `crypto.randomInt` ベース）。テストで再現できるようにするため
- ダイスの目は必ずサーバーで振る

### state
```
players, options, order: 席[], turnIdx, round,
map: { width, height, grid, regions },
owner: (席 | -1)[],   // 領土ごと。-1 = 中立
dice: number[],        // 領土ごと
stock: number[],       // 席ごとの持ち越し
out: boolean[], left: boolean[],
lastAttack: { seq, from, to, attacker, defender, aRolls, dRolls, success } | null,
lastReinforce: { seq, seat, added: { [regionId]: n }, stock } | null,
turnStartedAt, deadlineAt, phase: 'play' | 'over', winner: 席 | null, log
```

### action
| type | 条件 | 処理 |
|---|---|---|
| `attack` `{ from, to }` | 自分の番、`from` が自分の領土でダイス2個以上、`to` が隣接する他人か中立の領土 | 1章のとおり判定。`lastAttack` を更新。相手の領土が0になったら脱落、残りが1人になったら over |
| `endTurn` | 自分の番 | 補充して次の人へ（脱落者は飛ばす）。`lastReinforce` を更新 |
| `forceEndTurn` | ホスト、手番の人が切断中 | `endTurn` と同じ |

- `deadline` / `onTimeout`：`turnTime` が0以外なら、ターン開始から `turnTime` 秒。時間切れで `endTurn` と同じ処理
- `turnOf`：play 中は手番の人
- `isOut`：脱落した人・退席した人
- `onLeave`：その人の領土を **中立** にする（ダイスはそのまま）。手番中ならターンを次へ進める（補充なし）。残りが1人なら over
- `spectatorView`：隠し情報がないので `view` と同じ内容でよい

### view
```
map: { width, height, grid, regions(id, neighbors, center) },  // 地図は変わらないが、毎回送ってよい（数KB）
owner, dice, stock, players: [{ id, name, color, out, left, regions: 数, totalDice, largest: 最大のかたまり }],
order, currentId, round, lastAttack, lastReinforce, deadline, phase, winnerId, log
```
- `color` はサーバーで席に割り当てる（5章の6色）

## 5. 画面（games/dicewar/client.js / client.css）

### 5-1. 地図（.felt の中）
- **SVG** で描く。`viewBox` を地図に合わせ、幅100%で縮むようにする（横スクロールさせない）
- 各マスを六角形の `<polygon>` で塗る（持ち主の色）。海は描かない（フェルトが見える）
- 領土の境目：隣のマスと領土が違う辺だけ、太めの線（濃い茶色）を引く。同じ領土の中のマスの境目は線を引かない
- 各領土の `center` のマスに、**ダイス数のラベル**（白い丸に太字の数字。ダイスが8個の領土は金色の縁）を置く
- 中立の領土は、薄いベージュに斜線模様
- プレイヤーの色（色の違いが分かりにくい人のため、明るさも変える）：
  `#d9534f`（赤）`#3f7fbf`（青）`#e8b33a`（黄）`#5aa36b`（緑）`#8e5bb5`（紫）`#e07b39`（橙）
  - 色だけに頼らないよう、各領土のラベルの左上に、持ち主の番号（1〜6）を小さく添える

### 5-2. 操作（自分の番）
1. 攻撃元を選ぶ：攻撃できる自分の領土（ダイス2個以上で、攻撃できる隣があるもの）を少し明るくする。タップで選ぶと、その領土を金色の縁で強調する
2. 攻撃先を選ぶ：攻撃できる隣の領土を点滅（ゆっくり）させる。タップで攻撃する
3. 攻撃元をもう一度タップすると、選択を解除する。地図の外をタップしても解除する
4. 下に大きく **「ターン終了」** ボタン（primary）。残り時間（`timerHTML`）を横に出す
5. 攻撃の結果が返るまでは、次の攻撃を受け付けない（二重送信の防止）

- 操作できない人（他人の番・観戦者）は、地図を見るだけ
- 領土をタップすると、その領土の持ち主・ダイス数を小さく表示する（誰でも）

### 5-3. 攻撃の演出
`ctx.prev` と比べて `lastAttack.seq` が変わったら：
1. 攻撃元と攻撃先の領土を結ぶ矢印を表示する
2. 地図の下（または上）に結果パネルを出す：攻撃側と防御側のダイスの目を、小さなダイスの絵（⚀〜⚅ではなく、CSSで点を描いたダイス）で並べる。最初の0.6秒は目がランダムに切り替わり（転がる演出）、そのあと実際の目と合計を表示する
3. 結果「占領！」（攻撃側の色）／「防衛成功」を表示する。地図の更新は、演出が終わってから反映して見せる（演出中は前の状態の地図を描く）
4. `prefers-reduced-motion` のときは、転がる演出を省いてすぐに結果を出す
5. 演出中に次の更新が来たら、すぐ最新の状態にする（演出が溜まらないように）

`lastReinforce.seq` が変わったら：補充された領土のラベルを1秒だけ「+2」のように表示する。

### 5-4. .g-side
- **プレイヤー一覧**：色・名前・領土数・総ダイス・**最大のかたまり（＝次の補充数）**・持ち越し。手番の人を強調し、脱落者は薄く、順位順（領土数）に並べる
- 記録（.log）：「あき → べん：占領（22 対 11）」「しー：+9 補充」など、直近10件

### 5-5. ルール（export const rules）
1章を5〜7行の箇条書きにする。「同点は防御側の勝ち」「補充は最大のかたまりの数」を太字にする。

### 5-6. 効果音
| 条件 | 音 |
|---|---|
| 攻撃（演出開始） | `dice`（新規：短いノイズを40msずつ6回、間隔50ms、bandpass 1200Hz。ダイスがカラカラ転がる音） |

## 6. テスト
- `test/dicewar.map.js`：小・中・大 × 各3000回、地図を生成し、3章の検証条件をすべて満たすこと。`grid` の領土番号と `regions[].cells` が一致すること。隣接関係が対称であること
- `test/dicewar.random.js`（npm test に追加）：2〜6人 × 各500ゲームを、シード付きの乱数で、攻撃・ターン終了・時間切れ・切断・退席・ホストの強制終了の乱択で最後まで回す
  - 毎ステップ検証すること：
    - ダイスは各領土1〜8、持ち越しは0〜64
    - 攻撃成功時：攻撃元が1、攻撃先が「攻撃元の元の数−1」、持ち主が変わる
    - 攻撃失敗時：攻撃元が1、攻撃先は変化なし
    - 同点は必ず失敗になる
    - 補充後：自分のダイスの増加分＋持ち越しの増加分（捨てた分を含む）＝ 最大のかたまりの数＋前の持ち越し
    - 脱落者・退席者に手番が来ない
    - ルール違反の攻撃（自分の領土への攻撃・隣接していない・ダイス1個から・他人の番）はすべて `{ error }`
    - 終了時、生存者が1人以下（または100周の打ち切り）
- `test/client.smoke.js` に dicewar が含まれることを確認する
