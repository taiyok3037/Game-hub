# 仕様 07：チャットとルールの分離、PCでチャットを常に出せるレイアウト

ブランチ：`feature/chat-layout`
前提：CLAUDE.md、仕様01（.g-layout / .g-main / .g-side / ルールパネル）、仕様04（チャット欄・右列のタブ・スマホのボトムシート）。
**最初に現状のコード（public/index.html・app.js・chat.js・style.css）を読み、名前が違う箇所は実際のコードに合わせること。読み替えた箇所は報告に書く。**
今回は見た目と配置だけの変更で、サーバーとゲームのルールは変えない。

## 1. やりたいこと
1. **ルールとチャットを分ける**（今の「チャット｜ルール」のタブをやめる）
2. **PCではチャットを画面の左か右に常に出しておける**。邪魔なときはボタンで閉じられ、閉じたら卓が広がる
3. チャットが常に出ていても、卓・手札・得点表が窮屈にならないレイアウトにする

## 2. 決めごと
| 項目 | 決定 |
|---|---|
| チャットの位置 | 左右を選べる。**初期値は右**。チャット欄の見出しにある「⇄」ボタンで切り替える |
| チャットの開閉 | PCでは **初期値は開いた状態**。ゲームバーの「チャット」ボタンで開閉する |
| 開閉・位置の保存 | 見ている人ごとに `localStorage`（`gamehub-chat-open` / `gamehub-chat-side`）。読み書きは必ず try/catch で囲み、使えないときは初期値で動く |
| ルールの置き場所 | 得点表などの `.g-side` の中に、**折りたたみ式の「ルール」欄** として置く（初期値は開いた状態・開閉は `gamehub-rules-open` に保存）。スマホでは専用のボトムシート |
| 閉じているときの新着 | ゲームバーの「チャット」ボタンに未読数のバッジを出す（今の仕組みを使う） |

## 3. 画面幅ごとの配置

### 3-1. ゲーム画面
`チャット` = チャット欄、`サイド` = `.g-side`（得点表・記録・観戦者一覧・ルール欄）、`卓` = `.g-main`

| 画面幅 | チャットを開いているとき | チャットを閉じているとき |
|---|---|---|
| **1100px 以上** | 3列：`サイド 260px` ｜ `卓（可変・最大640px）` ｜ `チャット 320px`（位置が左なら左右を入れ替え：`チャット｜卓｜サイド`） | 2列：`サイド 260px` ｜ `卓（最大720px）` |
| **768〜1099px** | 2列：`卓（可変）` ｜ `チャット 300px`（左なら入れ替え）。`サイド` は卓の下 | 1列：`卓`、その下に `サイド` |
| **767px 以下** | チャットは **ボトムシート**（今と同じ）。ゲームバーの「チャット」ボタンで開く | — |

- 全体の最大幅は **1440px**（今の1240pxから広げる）。中央寄せ
- ゲームバーは、その時の全体幅に合わせる
- グリッドは `grid-template-columns` を `minmax(0, 1fr)` で組み、どの幅でも横スクロールを出さない
- チャットの列：`position: sticky; top: 16px; height: calc(100dvh - 32px)`。中は「見出し → メッセージ一覧（ここだけスクロール）→ リアクション列 → 入力欄」の縦並びで、入力欄は常に列の一番下に見えている
- 開閉したときに、卓の描画（SVGの地図など）が新しい幅に合わせて描き直されること。各ゲームは幅100%で描いているので、基盤は開閉後に `resize` イベントを1回出せばよい

### 3-2. ロビー
| 画面幅 | 配置 |
|---|---|
| **900px 以上** | 2列：`ロビーの紙パネル（最大560px）` ｜ `チャット 320px`（位置が左なら入れ替え）。チャットの開閉はゲーム画面と共通の設定 |
| **899px 以下** | 今と同じ（紙パネルの下にチャット欄） |

### 3-3. スマホ（767px以下）のゲームバー
- 「ルール」ボタンと「チャット」ボタンを **別々に** 置く（アイコン＋文字。「チャット」には未読バッジ）
- それぞれ別のボトムシートを開く。シートの中にタブは置かない
- ゲームバーが狭いときは、ボタンの文字を隠してアイコンだけにする（`aria-label` は必ず付ける）

## 4. 部品の変更

### 4-1. チャット欄（public/chat.js）
- 「チャット｜ルール」のタブを削除し、チャット欄は **チャット専用** にする
- 見出し：「チャット」＋ 位置切り替えボタン「⇄」（`aria-label="チャットを左に移動"` / 「右に移動」）＋ 閉じるボタン「×」（PCのみ。`aria-label="チャットを閉じる"`）
- 同じ1つのチャット部品を、PCの列・スマホのシート・ロビーの欄で使い回す（DOM を移動させる。メッセージの履歴と未読の状態を二重に持たない）

### 4-2. ルール欄
- `.g-side` の一番上に `<details class="rules-box paper">` を置く。中身は各ゲームの `export const rules`
- `<summary>` は「ルール」。開閉の状態を保存して、次のゲームでも同じ状態にする
- `.g-side` を持たないゲームでも、基盤が卓の下にルール欄を出す
- 今の「右列のルールパネル」と、スマホの「チャット｜ルール」のシートは削除する

### 4-3. ゲームバー
- PC：「チャット」トグルボタン（`aria-expanded`、`aria-controls`）。閉じているときだけ未読バッジを出す
- スマホ：3-3 のとおり

## 5. 確認項目（完了条件）
各項目を、**1600 / 1280 / 1000 / 900 / 390px** で確認する。可能なら、ヘッドレスブラウザ（Playwright など）で各幅のスクリーンショットを撮り、報告に添える（撮れない環境なら、その旨を書く）。
- [ ] ルールとチャットが別々の場所にあり、タブで切り替える作りがなくなっている
- [ ] 1280px：サイド｜卓｜チャットの3列で、チャットが常に見えている。卓（手札・地図）が窮屈になっていない
- [ ] 「⇄」でチャットが左に移り、サイドが右に移る。リロードしても左のまま
- [ ] 「チャット」ボタンで閉じると卓が広がり、新着でボタンに未読数が出る。もう一度押すと開く。リロードしても状態が残る

- [ ] ロビー（900px以上）で、紙パネルの横にチャットが出る
- [ ] ダイス領土戦の地図が、チャットを開閉しても正しい大きさに描き直される
- [ ] 全6ゲームで崩れない。どの幅でも横スクロールが出ない
- [ ] チャットの入力欄が、メッセージが多くても常に見えている
- [ ] シークレットウィンドウ（localStorage が使えない状況を含む）でも初期値で動く
