# 仕様 08：レイアウトの手直し（チャットの高さ・ルームコードのコピー・ルール欄）

ブランチ：引き続き `feature/chat-layout`（まだ main にマージしていないため、同じブランチで直す）
前提：仕様07の実装（#chat-col / .game-grid / #chat-sheet / #rules-sheet / .rules-box / test/shots.mjs）。
**最初に現状のコードを読み、名前が違う箇所は実際のコードに合わせること。**

## 実際に遊んで見つかった問題
1. **PCでチャット列の下部が見切れる**（入力欄・リアクション列が画面の外に出る）
2. **ルームコードをクリックするだけでコピーしたい**
3. **ルールが急に消えたり出てきたりする**
4. **ルールを折りたためることが分かりにくい**
5. （ついでに）チャットのリアクション列に横スクロールバーが見えていて見た目が悪い

## 1. チャット列の高さ

### 原因
チャット列が `top: 16px; height: calc(100dvh - 32px)` になっているが、列の開始位置はゲームバーの下（画面上端から約150px）なので、スクロールしていない状態では、その分だけ下にはみ出す。

### 直し方
- チャット列の高さを **「画面の高さ − 列の上端の位置 − 16px」** にする。上端の位置は、ゲームバーの高さを含めて決まるので、CSSだけで合わせにくい場合は JS で計算してよい
  - `resize` と `scroll` のときに、`#chat-col` の `getBoundingClientRect().top` を見て、`--chat-h = innerHeight − max(top, 16) − 16` を設定する（`requestAnimationFrame` でまとめる）
  - さらに **最大 640px、最小 360px** に収める（高すぎると間延びし、低すぎると使えないため）
- ロビーの2列表示のチャットも同じにする
- チャット列の中は「見出し → メッセージ一覧（ここだけ伸び縮み・スクロール）→ リアクション → 入力欄」。メッセージ一覧以外は高さ固定で、**入力欄は必ず列の中に見えている**こと

### 確認（test/shots.mjs に追加）
次の画面サイズで、ゲーム画面とロビーを開き、**チャットの入力欄の下端が画面内（`rect.bottom <= innerHeight`）にあること** をプログラムで確かめる。結果を報告に書く。
- 1920×1080、1366×768、1280×720、1165×870、1000×700

## 2. ルームコードをクリックでコピー

- ゲームバーの「卓 5LQK」と、ロビーの大きなルームコードを **`<button>`** にする
  - 押すと **ルームコード（4文字）** をクリップボードにコピーし、トースト「ルームコード 5LQK をコピーしました」を出す
  - 見た目：今の見た目のまま、横に小さなコピーのアイコン（インラインSVG）を添える。マウスを乗せると少し明るくなり、`title="クリックでコピー"`
  - `aria-label="ルームコード 5LQK をコピー"`
- ロビーの「招待リンクをコピー」ボタンは残す（リンクで送りたい人向け）
- クリップボードが使えない環境（`navigator.clipboard` が無い・失敗した）では、一時的な `<textarea>` を使った方法で試し、それも失敗したらトーストで「コピーできませんでした。5LQK を手で入力してください」と出す

## 3. ルールが消えたり出てきたりする

### 原因（想定。コードで確かめること）
ルール欄が、ゲームが毎回まるごと描き直す `.g-side` の中に入っている。そのため、更新のたびにいったん消えてから差し込み直されていて、タイミングによっては差し込みが漏れる（きゅうりのトリック保留表示の再描画など）。

### 直し方
- ルール欄を **基盤が持つ、描き直されない場所** に移す
  - サイドの列を基盤側の入れ物 `#side-col` にし、その中を「`#rules-box`（基盤が1回だけ作る）」と「`#side-slot`（ゲームの `.g-side` を入れる場所）」の2段にする
  - 各ゲームの `render` が終わったら、基盤がゲームの出力から `.g-side` を取り出して `#side-slot` に移す（`.g-side` が無いゲームでは `#side-slot` を空にする）
  - `#rules-box` は、ゲームが始まったとき（ゲームの種類が決まったとき）に1回だけ中身を入れる。以降の更新では触らない
- 画面幅が狭くて `.g-side` が卓の下に回る場合も、`#side-col` ごと下に回る（ルール欄の位置が揺れない）
- スマホ（767px以下）は今のまま「ルール」ボタン → 専用シート。`#rules-box` は表示しない

## 4. 折りたためることを分かりやすく

`<details>` の小さな三角だけでは気づきにくいので、見出しを **はっきりしたボタン** にする。
- ルール欄の見出し行：左に「ルール」、右に **「隠す ▲」**（開いているとき）／**「表示 ▼」**（閉じているとき）という小さな丸いボタン
  - 見出し行全体を押しても開閉できる
  - `<button aria-expanded="true|false" aria-controls="rules-body">` を使う（`<details>` はやめる）
- 閉じているときは、見出し行だけの細い帯（高さ44px）になり、「ルール　表示 ▼」と表示される
- 開閉は 0.15秒でなめらかに（`prefers-reduced-motion` のときはすぐ切り替える）
- 開閉の状態は今までどおり保存する。**初期値は開いた状態**

## 5. リアクション列の横スクロールバー
- スクロールバーを隠す（`scrollbar-width: none` と `::-webkit-scrollbar { display: none }`）。横スクロール自体はそのままできる
- 列の右端に、まだ続きがあることを示すうっすらしたグラデーションを付ける
