# 仕様 09：迷言メーカー 第1弾ブラッシュアップ
（白紙カード／1枚ずつ発表＋読み上げ／みんなのいいね／表彰式／テーマ12種類）

ブランチ：`feature/meigen-v2`（**`feature/chat-fix` から切る**。チャットの修正もまだ main に入っていないため、あとで一緒にマージする）
前提：CLAUDE.md、仕様03〜05・07・08（観戦・チャット・ゲーム設定 options・タイマー・`{ silent: true }`・#side-col）。
**最初に現状の `games/meigen/` と基盤のコードを読み、名前が違う箇所は実際のコードに合わせること。読み替えた箇所は報告に書く。**

> データ（`games/meigen/data/`）は渡されたものをそのまま使い、中身を変えないこと。

## 0. データの変更点（渡すファイル）
- `themes/` に6テーマを追加して **12テーマ**（中二病のセリフ・悪役の最期の言葉・実況アナウンサー・架空の映画タイトル・意識高い系の名言・未来からの警告）
- `common.json` の単語を2つに分けた
  - `words`：ふつうの単語（290語）
  - `chaos`：「どうつながるんや？」系のカオス単語（280語）
- 共通カードの山は `words` と `chaos` を合わせて作る（今までと同じ570枚）。カードの `kind` を `'common' | 'chaos' | 'theme' | 'blank'` にする（表彰式の「カオス賞」で使う）

## 1. 白紙カード
- ゲーム設定に追加：`blankCards`「白紙カード」0〜3枚（初期値 **2**）。1ゲームを通して使える枚数
- 作成中（compose）、手札の横に **「白紙（残り2）」** のボタン。押すと入力欄が出て、言葉を書いて「追加」でフレーズの末尾に入る
  - トークン：`{ t: 'blank', text }`
  - 文字数：前後の空白を削って **1〜10文字**。改行・制御文字は不可
  - フレーズの条件「カードを最低1枚含む」は、白紙カードも1枚と数える
- **提出したときに消費する**（下書きの段階では消費しない。取り消したら戻る）。1つのフレーズに使える白紙は、残り枚数まで
- 見た目：白紙カードのトークンは、手書き風の書体（Google Fonts の `Yomogi` など）・点線の枠で、普通のカードと区別する
- 時間切れの自動提出に白紙カードが含まれていたら、それも消費する
- サーバーで検証：残り枚数・文字数・制御文字。違反は `{ error }`
- 表示は必ずエスケープする（ユーザーが入力した文字列のため）

## 2. 1枚ずつ発表
- ゲーム設定に追加：`revealMode`「発表のしかた」：**1枚ずつ**（初期値）／一度に全部
- 1枚ずつのとき、judge（選考）を2段階にする
  1. **めくる段階**：`revealed`（めくった枚数）が 0 から始まる。親が「次をめくる」を押すたびに +1。「残りを全部めくる」ボタンもある
  2. **選ぶ段階**：全部めくり終わったら、今までどおり親が選ぶ
- **view には、めくった分のフレーズの本文だけを送る**。めくっていない分は「裏向きが何枚あるか」だけ（開発者ツールで先読みできないように）
- 親が切断している間は、ホストが「全部めくる」を押せる
- 画面：めくった短冊は、裏から表に回転して現れる（0.4秒。`prefers-reduced-motion` のときは即時）。めくったときに `flip` 音

## 3. 読み上げ
ブラウザの音声合成（`speechSynthesis`、日本語の声）でフレーズを読み上げる。**完全にブラウザ側だけ**の機能（サーバーは関係ない）。
- 読み上げるタイミング
  - 作成が始まったとき：お題（例：「お題。給食のプリンを3つ食べた」）
  - 短冊がめくられたとき：そのフレーズ
  - 発表（result）のとき：選ばれたフレーズ（「選ばれたのは、〜」）
- ゲームバーに **「読み上げ」トグル**（スピーカーに吹き出しのアイコン、`aria-pressed`）。見ている人ごとに `localStorage`（`gamehub-tts`）に保存し、**初期値はオン**
  - 効果音の全体ミュート中は読み上げもしない
  - 日本語の声（`lang` が `ja` で始まるもの）が見つからないブラウザでは、トグルを出さない
- 声：日本語の声のうち最初のもの。フレーズごとに高さ（pitch）を 0.9〜1.3 でランダムに少し変える（面白さのため）。速さ 1.0
- 新しく読み上げるときは、前の読み上げを止める（`speechSynthesis.cancel()`）
- ブラウザの自動再生制限に備えて、最初のクリック（効果音のロック解除と同じタイミング）で、空の発話を1回流しておく
- 1つの部品（`public/lib/speech.js`：`speak(text, { pitch })` / `isAvailable()` / `setEnabled()`）にまとめ、今後のゲームでも使えるようにする

## 4. みんなのいいね
- 選考中（めくられた短冊）と発表中に、**親以外のプレイヤーと観戦者・脱落者** が、短冊に「いいね」を付け外しできる
  - 1人1つの短冊につき1回（付ける／外すの切り替え）。複数の短冊にいいねしてよい
  - **自分の作品にはいいねできない**（サーバーで拒否。作者が誰かは返さない）
  - 親はいいねできない（親の選択と混ざらないように）
- 点数には **入らない**。表彰式で使う
- いいねの数は全員にリアルタイムで見せる（短冊の右下に「♥ 3」）。誰が押したかは見せない
- 発表（result）の画面で、いいねが一番多かった短冊に「みんなの推し」のバッジを付ける（同数なら全部）
- **基盤の追加**：観戦者・脱落者からの `game:action` は、今は拒否している。ゲームが `spectatorActions: ['like']` のように宣言した action だけは、観戦者からも受け付けるようにする（`playerId` には観戦者の id を渡す）
- 連打への備え：1人あたり1秒に5回まで（超えたら無視）

## 5. 表彰式
ゲームが終わったら（over）、結果画面の前に **表彰式** を見せる。賞はサーバーで計算して view に入れる（いいねや作者の情報を使うため）。

### 賞の一覧（該当者がいない・全員0の賞は出さない。同数なら全員受賞）
| 賞 | 対象 |
|---|---|
| 🏆 優勝 | 目標点に達した人 |
| いいね王 | もらったいいねの合計が一番多い人 |
| 名作賞 | このゲームで一番いいねが多かった短冊（作者・フレーズ・お題を表示） |
| カオス賞 | 提出したフレーズに使った **カオス単語（kind=chaos）の数** の合計が一番多い人 |
| 白紙の魔術師 | 白紙カードを使ったフレーズが **選ばれた** 回数が一番多い人（0回なら出さない） |
| 大作賞 | 提出したフレーズのうち、一番 **文字数が多い** フレーズの作者 |
| ひとことで勝負賞 | 選ばれたフレーズのうち、一番 **文字数が少ない** フレーズの作者 |

- 発表の演出：賞を1つずつ、1.2秒おきに表示する（賞の名前 → 少し間をおいて受賞者）。最後に優勝を大きく出す。各賞で `ready` 音、優勝で `win` 音
- 全員の画面で同じ順に出す（演出はクライアント側。`prefers-reduced-motion` なら全部まとめて表示）
- 下に「今日の選ばれた迷言」一覧（ラウンド・お題・作者・フレーズ・いいね数）
- 「ロビーに戻る」は今までどおり（ホスト）。演出の途中でも「全部表示」ボタンでスキップできる
