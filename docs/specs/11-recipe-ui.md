# 仕様 11：喫茶店のレシピ帳の見やすさ改善 ＋ ホーム・ロビーからルールを見られるように

ブランチ：引き続き `feature/recipe`（まだ main にマージしていないため）
前提：仕様07・08（#side-col / ルール欄 / チャット列）、仕様10（喫茶店のレシピ帳）。
**最初に現状のコードを読み、名前が違う箇所は実際のコードに合わせること。読み替えた箇所は報告に書く。**

## 実際に遊んだ感想（スクショあり）
1. 今持っている材料チップの **合計数** を出してほしい
2. 各カードの **レシピ名の色が薄い**
3. **自分のステータスが見にくい**。このゲームは自分の情報をメインに、他の人の情報は控えめでよい
4. **ゲームの選択画面（ホーム）とロビーからもルールを見たい**
5. （スクショで見つかった不具合）幅790px前後で、**チャット列が卓の上に重なる**

## 1. 自分の手元パネル（メイン）
`.g-main` の中、**卓（.felt）のすぐ下** に、自分専用の大きな紙のパネル「あなたの手元」を置く。スマホでも卓のすぐ下（得点表やルールより上）。

### 中身
- 1行目：名前・**点数（大きく）／勝利点**・点数のバー・予約「2 / 3」・来店した常連さん（小さな札を並べる）
- **材料の表**（6列：コーヒー豆・ミルク・抹茶・いちご・はちみつ・スパイス）
  | 行 | 内容 |
  |---|---|
  | 割引 | 作ったレシピの数（スパイスの列は「—」） |
  | チップ | 手元のチップの数 |
  | **使える数** | 割引＋チップ（スパイスはチップの数）。**一番大きな文字**。カードのコストと直接比べられる数 |
  - 各列の上に材料アイコン（大きめ・32px）と名前
- **チップの合計**：「手元のチップ **7 / 10**」を表の右（スマホでは表の下）に大きく出す。8〜9枚で黄色、10枚で赤にする
- **予約したカード**：小さめのカードで横に並べる。タップすると、場のカードと同じパネル（作る）が出る
- 自分の番のときは、パネルのふちを金色にする（手番の演出と同じ）

### 観戦者・脱落者
- 「あなたの手元」の代わりに、**今の手番の人** の手元を同じパネルで表示する（見出しは「たこすけ の手元」）。seesAll=false のとき、山から予約したカードは伏せる

## 2. 他の人の情報（控えめに）
- `.g-side` のプレイヤー欄を、**1人1〜2行のコンパクト表示** にする
  - 1行目：名前・点数・手番の印
  - 2行目：割引を材料アイコン＋数字で小さく（0の材料は出さない）、チップ合計「チップ 6」、予約「予約 1」
  - タップすると、その人の詳細（材料ごとのチップ・予約の中身〈見られる分〉・来店した常連さん）が開く。もう一度タップで閉じる
- 自分は一覧に出さない（手元パネルにあるため）。観戦者・脱落者のときは全員を出す
- 記録（.log）は今のまま（.g-side の一番下）

## 3. カードを読みやすく
- レシピ名・コストの数字・点数は、**紙の背景に対してコントラスト比4.5:1以上** の濃い色（`--ink`）にする
- **作れないカードを全体的に薄くしない**。代わりに：
  - 作れるカード：金色のふち＋右下に小さく「作れる」
  - 作れないカード：ふつうの見た目のまま、右下に **「あと3」**（足りない数。割引とチップとスパイスを使っても足りない数）を小さく出す（自分の番でなくても表示してよい）
- コストの各材料の丸に、**自分の「使える数」で足りているか** を小さな印で出す（足りている材料は ✓、足りない材料は数字を赤）。色だけに頼らず、記号でも分かるようにする
- 段階の帯の色（まかない／定番／看板）は今のまま

## 4. ホームとロビーからルールを見る（基盤）
- **ホーム**：各ゲームの箱の右下に「ルール」の小さなボタン（箱を押してルームを作る動きとは別にする。`stopPropagation`）。押すと、そのゲームのルールをダイアログ（紙のパネル、閉じるボタン、背景タップ・Escで閉じる）で表示する
  - ルールの本文は、各ゲームの `client.js` の `export const rules` を、必要になったときに `import()` して取り出す（ホームの表示が重くならないように）
- **ロビー**：紙パネルのゲーム名の下に、ゲーム中と同じ部品のルール欄（「隠す ▲／表示 ▼」）を置く。ロビーでは **初期値は開いた状態**（保存キーはゲーム中と別：`gamehub-lobby-rules-open`）
- `rules` を持たないゲームでは、ボタン・欄を出さない

## 5. 幅790px前後でチャットが卓に重なる不具合
- 原因（想定）：2列表示（768〜1099px：卓｜チャット）で、卓の中身（カード5列など）の最小幅が列の幅より大きく、はみ出している
- 直し方：
  - グリッドの卓の列を `minmax(0, 1fr)` にし、卓側の要素にも `min-width: 0` を付ける
  - カードの幅を、卓の幅に合わせて縮む指定にする（例：場の行を `grid-template-columns: repeat(5, minmax(0, 1fr))`、カードの文字は `clamp()` で少し縮む）
  - それでも狭い幅（目安：卓の列が 560px 未満になる幅）では、チャットを列ではなく **ボトムシート**（スマホと同じ）に切り替える。基盤側で、卓の実際の幅を見て判断してよい
- 全ゲームで確認する（ダイス領土戦の地図、迷言メーカーの短冊も同じ問題がないか）

## 6. 制限時間の初期値（このゲームだけ）
- 喫茶店のレシピ帳の `turnTime` の初期値を **90秒** にする（考えることが多いため）
